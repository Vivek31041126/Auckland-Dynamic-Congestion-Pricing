## Featured Project

### Auckland Dynamic Congestion Pricing

An end-to-end research project that combines SUMO traffic simulation, ARIMA/XGBoost/LSTM forecasting, dynamic toll design, behavioural response modelling, congestion feedback analysis, MQTT-based streaming, and an interactive Gradio dashboard.

Repository:
